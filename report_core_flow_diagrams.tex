};

  票券仍維持 CONSUMED
};

\draw[dashedarrow] (consumed) -- (crash);

\end{tikzpicture}

\vspace{5mm}
\begin{block}{Lifecycle boundary}
Fresh nonce 可阻止舊 transcript replay，但不能阻止合法持有者使用同一張
ticket 回應新的 challenge；後者必須由 consumption state 處理。
\end{block}

\end{frame}
