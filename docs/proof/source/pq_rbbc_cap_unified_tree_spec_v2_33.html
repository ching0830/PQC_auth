PQ-RBBC v2.33 Unified-Tree CAP Candidate Specification

Status: exact candidate algorithm and reduced executable profile; not a frozen or qualified production profile. Date: 2026-09-04.

Claim boundary. This document defines a new, independent namespace. It does not modify or replace the legacy 18-root profile, does not validate a production CAP proof, and does not authorize production pre-freeze, relation replay, or proving. Existing tree stream sizes, assignments, digests, and v2.29 transcripts are not observations for this profile.

1. Sources and notation

The optimized BAVC construction follows Section 3.1 of ePrint 2024/490: one GGM tree with L leaves, a bijection π from leaves to logical vector positions, minimal frontier compression, and opening abort when |S| exceeds Topen. Counter grinding and the extra challenge bits follow Section 4. The selected Blind-UOV parameter row is cross-checked against Tables 4 and 7 of ePrint 2024/541. CAP integration requirements originate from the 2025-10-31 revision of ePrint 2025/895.

All indices below are zero-based. LE16, LE32, and LE64 are canonical unsigned little-endian integers. FE is a 25-byte little-endian GF(2193) element whose top seven bits are zero. H386 is a 49-byte little-endian 386-bit value whose top six bits are zero. Every XOF input is the repository's tuple-injective Anemoi sponge frame.

3. Tree topology and π mapping

The tree has one sampled root seed k0, internal heap indices 0…L−2, and leaf heap indices L−1…2L−2. For each internal node j in increasing order:

(k[2j+1], k[2j+2]) = XOF(seed-derive,
  profile_fingerprint, salt, FE(k[j]), LE32(j), 386 bits)

Consequently the exact number of seed-derive calls is L−1: 40,959 for the production candidate and 11 for the reduced profile. The earlier L−2 planning value is invalid for a construction that samples a single root.

For logical vector α and position i, define the position-major bijection:

π(α,i) = Σβ min(i,Nβ) + |{ β : 0 ≤ β < α and i < Nβ }|

For production, positions 0…2047 contain α=0…17 in order. Positions 2048…4095 contain only α=0,1. The corresponding heap leaf is L−1+π(α,i). The inverse chooses the unique position i for which Σβ min(i,Nβ) ≤ u < Σβ min(i+1,Nβ), then selects the indexed eligible α. No legacy tree number or legacy observed byte length participates in π.

4. Leaf material and batch commitment

Let metadata be LE16(α)||LE32(i)||LE32(π(α,i)). For each leaf seed sd, compute:

com[α,i] = XOF(seed-commit,
  profile_fingerprint, salt, FE(sd), metadata, 386 bits)
tape[α,i] = XOF(tape-expand,
  profile_fingerprint, salt, FE(sd), metadata, tape_bits)

Logical vector digests and the one batch root are:

h[α] = XOF(vector-hash,
  profile_fingerprint, LE16(α), LE32(Nα), H386(com[α,0]),..., 386 bits)
h     = XOF(root-hash,
  profile_fingerprint, LE16(τ), H386(h[0]),...,H386(h[τ-1]), 386 bits)

The decom commitment is the one root seed. Public commitment bytes are:

"PQRBBC-CAP-UGGM-COMMIT-V1" || LE16(1) ||
profile_fingerprint[32] || FE(salt[0]) || FE(salt[1]) || H386(h)

The parser requires the exact length, magic, version, profile fingerprint, canonical high bits, and no trailing bytes.

5. Challenge decoding and grinding

challenge_prefix is the exact canonical CAP transcript prefix that will later contain the public statement and all pre-h3 commitment material. The reduced vector uses the literal byte string PQ-RBBC/v2.33/reduced/challenge-prefix. Compute:

h3 = XOF(h3,
  profile_fingerprint, challenge_prefix, commitment_bytes, LE64(counter),
  386 bits)

Starting at bit 0, interpret h3 LSB-first. Consume one slice of log2(Nα) bits for α=0…τ−1; each slice is i(α). The next w bits are the explicit PoW value. A candidate is acceptable iff those w bits are zero and the canonical frontier has at most Topen nodes. Prove starts at counter zero, increments without wrap, and returns the first acceptable candidate. Verify need not rescan earlier counters, but recomputes h3 and both acceptance conditions. No generic leading-zero test may replace these rules.

6. Canonical minimal frontier

Initialize S with every heap leaf except the τ leaves selected by i(α). For j=L−2 down to 0, if both children 2j+1 and 2j+2 are in S, delete them and insert j. Sort the final S by strictly increasing heap index. This is the only accepted frontier; duplicates, reorderings, ancestors overlapping descendants, and a non-minimal equivalent cover are rejected.

Opening bytes are:

"PQRBBC-CAP-UGGM-OPEN-V1" || LE16(1) || profile_fingerprint[32] ||
LE64(counter) || H386(h3) || LE16(τ) ||
for α=0..τ-1: LE16(α) || LE32(i(α)) || H386(com[α,i(α)]) ||
LE16(|S|) || for j in increasing S: LE32(j) || FE(k[j])

The encoding is variable length but bounded by Topen. Counts are explicit; unused slots and padding are forbidden.

7. Verify algorithm

  1. Strictly parse the commitment and opening under the selected profile.
  2. Recompute h3 from the exact challenge prefix, commitment bytes, and counter. Reject mismatched h3, decoded indices, or nonzero explicit bits.
  3. Recompute the unique minimal frontier indices and reject any different list or a list longer than Topen.
  4. Expand every supplied frontier seed using its heap index. Reject overlap, hidden-leaf disclosure, missing nonhidden leaves, or extra leaves.
  5. For every reconstructed leaf, recompute its commitment and tape. Insert the τ supplied hidden commitments, recompute every h[α] and h, and require exact equality with the public commitment.
  6. Return the nonhidden tapes only after all checks succeed.

8. Reduced qualification requirements

The reduced profile exhaustively covers all 64 hidden-index tuples. Its canonical frontier distribution must be exactly:

|S|123456
Tuples116201620

Thus 28/64 tuples pass Topen before the independent 2-bit explicit condition. Qualification requires: one accepted deterministic vector; exact round trips; full production π bijection without expanding production leaves; rejection of magic, length, transcript, h3, hidden-index, explicit-bit, Topen, hidden-commitment, and frontier-seed mutations; a fresh-cache run; an identity-bound interrupted/resumed run; and overwrite refusal.

Bounded implementation boundary. The reduced runner may execute only the 12-leaf profile. Production parameters are present for validation and mapping tests, but the implementation raises before expanding them unless a future, separately reviewed production phase is explicitly added. Reduced execution creates no assignment, BR1CS, proof, pickle, or log.
